# TS_Examples

A collection of example programs in Typescript


## Running it in Visual Studio Code (VSC)

After reopening the project in a Docker container, run:

```
$ npm install
```

in the terminal windows. This will (locally) install TypeScript
inside the container as a node package.

Then, run the TS compiler with:

```
$ npx tsc
```
