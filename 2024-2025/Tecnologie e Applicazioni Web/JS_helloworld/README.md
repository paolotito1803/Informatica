# Simple hello world application in JavaScript (Node.js)

Use this project as a starting point to experiment coding in JS


## Running it in Visual Studio Code (VSC)

- Ensure that Docker Desktop is up and running
- open VSC
- open folder containing this README file
- click the bottom-left button marked as "><"
- select "Reopen in Container" and wait until a container is started
- click on helloworld.js and then Run -> "Start debugging". Select
  Node.js as the debugger 
- alternatively, open a Terminal (Terminal -> New Terminal) and type 
  "node helloworld.js" at the command prompt
